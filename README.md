# FUTURE_FS_01 - Full-Stack Developer Portfolio

A modern full-stack developer portfolio website built using React.js, Node.js, Express.js, and MongoDB. The portfolio showcases projects, technical skills, GitHub repositories, and includes a fully functional contact form with backend and database integration.

## 🚀 Live Demo
https://portfolio-website-two-ecru-82.vercel.app

---

## 📌 Features

- Modern dark futuristic UI
- Fully responsive design
- Smooth animations using Framer Motion
- Interactive hero section
- Project showcase section
- Skills and education sections
- Functional contact form
- Backend API integration
- MongoDB database integration
- Resume download feature
- GitHub and LinkedIn integration
